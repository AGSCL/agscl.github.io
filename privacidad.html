Política de privacidad

Esta política describe cómo uso los datos de mi cuenta de Google en el proyecto «Sincronización personal de Andrés».

Acceso y uso

Autorizo a overGrive a consultar mi cuenta, los archivos y carpetas de Drive, sus identificadores, sus metadatos y el contenido necesario para mantener las copias sincronizadas. La aplicación usa estos permisos para detectar cambios, descargar y subir archivos, y reflejar las eliminaciones según las preferencias elegidas.

Almacenamiento y transferencia

Los archivos sincronizados se transfieren entre el computador y Google Drive. El computador guarda las copias locales, la autorización de acceso y los registros de actividad, que pueden incluir nombres e identificadores de archivos. Esta configuración es de uso personal. Los permisos de uso compartido de cada archivo se administran en Drive.

Las páginas de este sitio contienen únicamente información sobre el proyecto. GitHub Pages aloja el sitio y registra la dirección IP de las visitas por motivos de seguridad. Información de GitHub Pages.

Revocación y eliminación

El acceso se puede revocar desde las conexiones de la cuenta de Google. Al revocarlo se interrumpe el acceso futuro. Las copias ya descargadas se conservan hasta que su propietario las elimine. Para borrar solamente las copias locales, primero se debe desconectar la cuenta de overGrive.

Contacto

Para consultas sobre esta configuración, utiliza el correo de asistencia que figura en la pantalla de consentimiento de Google del proyecto.
